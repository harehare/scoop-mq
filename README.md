# scoop-mq

[Scoop](https://scoop.sh) bucket for [mq](https://github.com/harehare/mq), a jq-like command-line tool for Markdown processing.

## Install

```powershell
scoop bucket add mq https://github.com/harehare/scoop-mq
scoop install mq/mq
```

Installs `mq`, `mq-lsp`, `mq-fmt`, `mq-check`, `mq-lint`, `mq-test`, `mq-crawl` and `mq-dbg`.
